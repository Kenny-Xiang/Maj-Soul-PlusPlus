# 稳定版四臂最终结果独立分析

**冻结研究筛查：rejected-screen。** 本文基于四个已完成固定5000步模型、完整自然holdout和最终decision；未使用早期streamingloss作质量结论。历史正式政策仍为not-assessed。

独立复核1368项动作比例、总量和来源计数恒等式。四模型中是否有一个在内部holdout所有适用动作严格>75%：False。该内部三麻结论不认证四麻或最终外部泛化。


当前最有辨别力的结论是：**混合目标确实提高多个稀有动作的完整召回，但没有解决候选内选牌，并伴随严重误报；两个初始化种子的学习状态又明显不同。** 两个seed的D改善区间都在0以上，仍各有9项冻结guard失败，不能按平均欠缺改善扩大这项处理。

- seed42的弃牌多候选条件Top1在fit/holdout约40.43%/40.37%，mix后几乎不变；自然完整弃牌仅37.74%。训练侧已很弱，不能把它仅解释为留出泛化失败。
- seed43的对应fit/holdout条件Top1约69.71%/68.92%，mix变为69.54%/68.73%。同一数据与预算下明显的seed差异，使“初始化/优化/结构交互导致学习差异”值得结合独立gating审计继续区分；聚合本身不能确定哪个机制。
- seed42-mix的大明杠100%完整召回伴随16,627次误选，precision只有2.424%、负例FPR99.551%；seed43-mix的52.785%召回仍伴随969次误选，precision18.366%。这两种结果都不是接近质量通过。
- 两来源均出现弃牌/过退化以及立直/杠召回提高，不能把该取舍单独归咎于新增来源。fitMonitor大明杠仅12正例，其100%不是强泛化证据。

## 证据所支持的后续判断

这组固定混合目标没有通过原预声明筛查；不得只凭D/召回改善扩大，也不得在同一holdout上改mix比例、偏置或guard直到通过。保留失败项目本身，作为目标取舍的证据。
两个自然臂连fitMonitor的弃牌多候选条件Top1也低于75%，因此候选内学习仍值得定位。这个结果不等于已证明容量不足、训练步数不足或门控病因；结合单独训练侧gating审计和本指南的最小直接交互对照设计，再决定是否值得新增结构实验。

目标取舍的理论边界：按真实动作类型乘正权重，在充分表达、达到总体最优的理想条件下，会重加权P(type|state)，但同类型条件P(candidate|type,state)中的类型系数相消。观察到候选内排序变化，只能结合有限样本、共享参数与优化预算解释，不能称新的目标要求改变基础牌标签。

本次未读取gating审计结果，不替它作结论。两种子、固定预算、三麻内部自然holdout限制仍然存在；混合目标与自然对照的变化可以解释本次处理效应，不能据此给出全量学习能力上限。用户完整动作>75%、研究screen和历史正式验收保持三列独立。
