# 雀魂规则与游戏机制

## 0. Agent 使用约定

雀魂采用日本立直麻将。不能直接套用国标麻将、四川麻将、港式麻将、天凤或 M 联赛的全部规则。本文以普通段位场为默认；友人场、比赛场和活动玩法可能覆盖这些默认值。

使用本文时遵守以下顺序：

1. 先确认服务器、四人/三人、东风/半庄、段位/友人/比赛/活动，以及自定义规则。
2. 分开判断“牌型完成”“有役”“允许荣和”“最后计多少点”，不能合并为一个判断。
3. 未提供的信息写为“未知”。不能凭截图猜测他家手牌、里宝牌、牌山顺序、未显示的舍牌或先前见逃记录。
4. 役种、番数、符数、点数、顺位、段位积分、铜币是不同概念。
5. 第 12 节列出官方文本之间的差异。涉及这些边界时，以当前客户端规则及可复现牌谱为准，不把文档当作经过全部测试的规则引擎。

**最快阅读路径：** 判断能否和牌看第 2、4、5 节；计算点数看第 6 节；判断终局看第 7 节；三麻看第 8 节；游戏操作和段位看第 9、10 节；向 agent 提供牌局看第 11 节。

## 1. 基础对象与记谱

### 1.1 牌与座位

四麻使用 34 种、每种 4 张，共 136 张牌：万、筒、索各 1–9；东南西北；白发中。赤五替换对应普通五，并非额外增加牌。没有花牌，也没有作为万能牌的“癞子”。

数牌的 1、9 称老头牌；老头牌与全部字牌合称幺九牌。字牌不能组成顺子。

每局东家为庄家，其余为闲家。行动方向为东→南→西→北。上家是前一位行动者，在常规界面中位于左侧；下家位于右侧。“场风”由东场、南场等决定；“自风”是本局座位，会随轮庄改变。

### 1.2 本文记谱约定

这是便于 agent 交流的通用文字表示，不等于雀魂内部协议。

| 表示 | 含义 |
|---|---|
| `m / p / s` | 万 / 筒 / 索 |
| `1z 2z 3z 4z` | 东、南、西、北 |
| `5z 6z 7z` | 白、发、中 |
| `0m 0p 0s` | 对应花色的赤五；组牌和振听按五处理，计宝牌时保留赤牌属性 |
| `123m` | 一二三万 |
| `55p` | 一对五筒 |
| `111z` | 东的刻子 |

完整和牌例：`123m456m234p678s55p`。另行注明和牌张、门清/副露、荣和/自摸；仅这串牌不足以确定所有役和点数。

来源：[雀魂官方日麻入门说明数据，文章「日麻規則簡單說明」](https://www.maj-soul.net/homepage/scripts/NewsList.json)；[官方 FAQ](https://mahjongsoul.com/faq)。

## 2. 和牌的必要条件

### 2.1 三种基本完成形

| 完成形 | 条件 |
|---|---|
| 普通形 | 4 个面子 + 1 个雀头；面子是顺子、刻子或已宣告的杠子 |
| 七对子 | 7 种不同牌各一对；同种 4 张不能算两对；必须门清 |
| 国士无双 | 13 种幺九牌各至少一张，其中一种为对子；必须门清 |

顺子是同花色连续三张，不允许 `891`、跨花色或字牌顺子。杠子虽有四张，结构上仍只算一个面子；每宣告一杠，实体总张数比通常形多一张。三麻已拔出的北另记，不占面子或雀头。

通常持牌结构为 13 张，摸牌/取得和牌张后为 14 张；副露、杠、拔北应单独记录，不能只数画面底部的暗手。

### 2.2 合法和牌判定

普通段位场常时一番缚：必须至少有一个真正的役。**宝牌、赤宝牌、里宝牌、拔北宝牌都不是起和役。**

```text
结构完成？
  否 -> 不能和牌
  是 -> 至少有一个本模式认可的役？
          否 -> 无役，不能和牌；宝牌再多也不行
          是 -> 自摸，还是荣和？
                  自摸 -> 振听不阻止自摸，继续检查该动作是否合法
                  荣和 -> 必须不振听，并处在可荣和的事件窗口
```

“听牌”指差一张能形成完成形；“形式听牌”可以没有役，用于荒牌流局结算。不能因此推导为可以立即和牌。

“自摸”是取得自己摸到的和牌张；“荣和”通常是取得他家刚打出的牌，也包括规则允许的抢杠、抢北。荣和使对应玩家放铳。副露后的普通自摸本身不是役，只有门清自摸才有“门前清自摸和”。

来源：[官方 FAQ](https://mahjongsoul.com/faq)；[官方段位规则](https://mahjongsoul.com/news/46)。

## 3. 一局中的动作

| 动作 | 条件与效果 | 是否破坏门清 |
|---|---|---|
| 摸牌、打牌 | 通常轮到自己时摸一张，再打出一张 | 否 |
| 吃 | 仅能吃上家刚打出的数牌，组成顺子；三麻禁止 | 是 |
| 碰 | 可用任意他家刚打出的牌组成刻子 | 是 |
| 大明杠 | 用手中三张与他家弃牌组成杠子，补摸岭上牌 | 是 |
| 加杠 | 给已碰出的刻子追加第四张；存在抢杠窗口 | 已经副露 |
| 暗杠 | 自己持有四张相同牌并宣告；补摸岭上牌 | 否 |
| 立直 | 门清听牌，支付供托并锁定通常打牌选择，详见第 4 节 | 否 |
| 拔北 | 三麻专属，公开北作为拔北宝牌并补牌 | 否 |
| 跳过/见逃 | 放弃本次吃碰杠和等机会；见逃可能产生振听 | 本身不影响 |

吃、碰后直接打牌，不再先摸一张。鸣牌会改变行动顺序；不能假定下一次一定轮到原本的下家。

同一弃牌有多个请求时，基本优先级为：**荣和 > 碰/大明杠 > 吃**，不是谁点按钮快谁优先。

四麻禁止食替，包括吃碰后立即打出被鸣的同种牌，以及顺子另一端的筋食替。例如以手中 `23m` 吃 `1m` 后，不能立即打 `1m` 或 `4m`。最终以客户端允许的弃牌集合为准。

普通段位场允许食断，即副露断幺九；允许后付，即和牌时满足役即可，不要求第一次副露时就确定役。最后一张舍牌可荣和，但不能再吃碰杠。

来源：[中文官方对局规则](https://www.maj-soul.net/homepage/scripts/RuleList.json)；[官方入门说明](https://www.maj-soul.net/homepage/scripts/NewsList.json)；食替释义补充见 [Rule variations](https://riichi.wiki/Rule_variations)。

## 4. 立直、门清、振听

### 4.1 立直

基本条件：门清、打出宣言牌后听牌、持点至少 1000，且满足牌山末尾限制。1000 点变为场上的立直供托；宣言牌被荣和时，立直未成立，不收这根供托。流局通常把供托留到下一局。

立直后通常只能摸切，不能吃碰或自由换牌。仍可自摸、荣和，以及进行满足专门限制的暗杠；三麻拔北也须符合客户端限制。允许振听立直及空听立直，但不允许以自己占满四张、等待第五张的虚听冒充听牌。

关于“末尾还剩几张能立直”和“立直后哪些暗杠允许”，官方中日文本措辞有差异，见第 12 节。不要简单采用“听口不变就能进行任意杠”。

立直为 1 番；首巡未被鸣牌打断时宣告的两立直为 2 番，不与普通立直重复加算。一发需要立直成立后、规定的一巡内且未被鸣牌打断而和牌；杠和三麻拔北也会打断一发。

### 4.2 振听

振听限制的是**整副牌的荣和权**，不是只禁止荣和造成振听的那一张；有合法役时仍可自摸。

| 类型 | 触发 | 如何解除 |
|---|---|---|
| 舍牌振听 | 当前任一完成形待牌曾由自己打出 | 未立直时改变听口，使全部当前待牌均不在自己的弃牌历史中 |
| 同巡振听/临时振听 | 未立直时，放过他家能完成自己牌型的牌；即使该张无役也可能触发 | 到自己的下一个正常摸打周期解除；精确事件边界见第 12 节 |
| 立直后振听 | 立直后见逃和牌 | 本局不再恢复荣和，只能自摸 |

必须检查完整弃牌历史，包括自己打出后被他家吃碰杠走的牌；不能只看当前河里还可见的牌。赤五与普通五是同一牌种。拔出的北不属于弃牌，不因“之前拔过北”而产生舍牌振听。

示例：当前听 `2s/5s`，自己曾打过 `2s`，则他家打 `5s` 也不能荣和。

**防守推论：** 某家自己曾打出的同种牌，对该家的荣和是安全牌；不代表对另外几家安全，也不阻止对手吃碰。

来源：[官方 FAQ](https://mahjongsoul.com/faq)、[中文官方规则](https://www.maj-soul.net/homepage/scripts/RuleList.json)；无役见逃及完整振听定义补充见 [Furiten](https://riichi.wiki/index.php?mobileaction=toggle_view_desktop&title=Furiten)。

## 5. 役与宝牌

### 5.1 常规役速查

番数栏为“门清 / 副露”；`—` 表示副露不能成立。下表以普通段位场为范围。

| 役 | 番数 | 核心条件 |
|---|---|---|
| 立直 | 1 / — | 合法宣告立直后和牌 |
| 一发 | 1 / — | 立直后规定一巡内，未被鸣牌打断而和牌 |
| 门前清自摸和 | 1 / — | 门清自摸 |
| 平和 | 1 / — | 四顺子、非役牌雀头，以两面完成最后的顺子 |
| 一杯口 | 1 / — | 同花色同数字的两组顺子 |
| 断幺九 | 1 / 1 | 全部是 2–8 数牌 |
| 役牌 | 每项 1 / 每项 1 | 自风、场风、白、发、中对应的刻子或杠子 |
| 岭上开花 | 1 / 1 | 杠后岭上牌自摸；雀魂三麻拔北补牌自摸也可成立 |
| 抢杠 | 1 / 1 | 荣和他家加杠牌；国士可抢暗杠，抢北不额外给此役 |
| 海底摸月 | 1 / 1 | 普通牌山最后一张摸牌自摸 |
| 河底捞鱼 | 1 / 1 | 对应最后弃牌荣和 |
| 两立直 | 2 / — | 自己首次弃牌宣告立直，此前无人鸣牌 |
| 七对子 | 2 / — | 七种不同对子，固定 25 符 |
| 对对和 | 2 / 2 | 四组刻子/杠子及雀头 |
| 三暗刻 | 2 / 2 | 三组暗刻/暗杠；荣和补成的那组刻子不算暗刻 |
| 三杠子 | 2 / 2 | 三组已宣告的杠 |
| 三色同刻 | 2 / 2 | 三花色同数字的刻子/杠子 |
| 小三元 | 2 / 2 | 两组三元牌刻杠 + 第三种三元牌雀头；另计两项役牌 |
| 混老头 | 2 / 2 | 仅用 1、9、字牌；可与对对和或七对子复合 |
| 一气通贯 | 2 / 1 | 同花色 `123`、`456`、`789` 三顺子 |
| 三色同顺 | 2 / 1 | 三花色各有一组相同数字顺子 |
| 混全带幺九 | 2 / 1 | 每个面子和雀头均含幺九牌，含顺子及字牌 |
| 二杯口 | 3 / — | 四顺子组成两组一杯口；不另加一杯口或七对子 |
| 混一色 | 3 / 2 | 一种数牌花色 + 字牌 |
| 纯全带幺九 | 3 / 2 | 每个面子及雀头含 1 或 9，含顺子且无字牌 |
| 清一色 | 6 / 5 | 只用同一花色数牌 |

同一组东刻子在东场东家可同时算场风、自风，共 2 番。非场风、非自风的风牌刻子不是役牌。

常见排他关系：两立直不再加立直；二杯口不再加一杯口；清一色不再加混一色；纯全不再加混全。七对子与“四面子一雀头”的役不能按两种拆法混加。存在多种合法拆法时取高点法。

役的构成核对：[官方役种 FAQ](https://mahjongsoul.com/faq)。番数及副露减番补充：[Yaku](https://riichi.wiki/Nomi)、[役种明细](https://en.wikipedia.org/wiki/Yaku_(Japanese_mahjong))。后两项为社区资料，不代表所有平台均相同。

### 5.2 役满

| 役满 | 核心条件 |
|---|---|
| 国士无双 | 13 种幺九牌齐全，其中一种成对 |
| 四暗刻 | 四组暗刻/暗杠；双碰听只能靠自摸保持四暗刻，单骑可荣和 |
| 大三元 | 白、发、中三组刻杠 |
| 小四喜 | 三种风牌刻杠 + 第四种风牌雀头 |
| 大四喜 | 四种风牌全部为刻杠 |
| 字一色 | 全部为字牌 |
| 绿一色 | 仅使用 `2s3s4s6s8s6z`；不强制含发 |
| 清老头 | 全部为数牌 1、9 |
| 九莲宝灯 | 门清同花色 `1112345678999` 加任一同花色牌，不能有杠 |
| 四杠子 | 四组杠子并完成雀头；第四次杠后不是自动和牌 |
| 天和 | 庄家最初配牌即和 |
| 地和 | 闲家未被鸣牌打断的首次摸牌即和 |

雀魂采用双倍役满：**国士无双十三面、四暗刻单骑、纯正九莲宝灯、大四喜**。真正役满可复合；普通役与宝牌不再加进真正役满的番数。累计 13 番以上的数え役满按一个累计役满封顶，不因 26 番自动变双倍。

门清限制仍需保留：例如国士、四暗刻、九莲不能从开放副露构成。天和涉及特殊听型时按最高点解释，不机械采用动画展示的“最后一张”。

双倍、累计役满及高点法补充核对：[雀魂四麻规则记录](https://note.com/qar13ktk20/n/nf9c7cf0eb025)；官方确认役满复合与采用役见 [官方段位规则](https://mahjongsoul.com/news/46)、[官方 FAQ](https://mahjongsoul.com/faq)。

### 5.3 宝牌

每张有效宝牌加 1 番，但始终不能单独满足有役要求。宝牌可重叠计数，例如赤五同时被指示为宝牌可计两份；同种宝牌被多张指示牌重复指示也累加。

| 指示牌类别 | 指向顺序 |
|---|---|
| 数牌 | 同花色 `1→2→…→9→1` |
| 风牌 | `东→南→西→北→东` |
| 三元牌 | `白→发→中→白` |
| 三麻万子 | `1m↔9m` |

普通四麻各一张赤 `5m/5p/5s`；三麻各一张赤 `5p/5s`。里宝牌只有立直和牌者能获得。开杠增加杠宝牌指示，立直和牌时也可能有杠里宝牌。

雀魂暗杠立即翻杠宝牌；大明杠/加杠通常在补牌后打牌时才翻。日服详细规则还列出连续杠前的翻牌节点，因此不要假设每次杠一宣告就立即翻牌。拔北不翻新的杠宝牌指示牌。

来源：[官方入门说明](https://www.maj-soul.net/homepage/scripts/NewsList.json)、[中文官方规则](https://www.maj-soul.net/homepage/scripts/RuleList.json)、[日服详细规则](https://mahjongsoul.com/news/46)。

## 6. 点数结算

### 6.1 番、符与基本点

普通和牌先算役番，再加有效宝牌番。低于满贯时需要符：

| 符来源 | 符数 |
|---|---|
| 副底 | 20 |
| 门清荣和 | +10 |
| 自摸 | +2；平和自摸例外，保持 20 符；七对子固定 25 符 |
| 役牌雀头 | +2；雀魂连风雀头，即自风=场风时，为 +4 |
| 单骑、嵌张、边张 | +2；不把同一和牌张按多种等待重复加符 |
| 中张明刻 / 暗刻 | +2 / +4 |
| 幺九明刻 / 暗刻 | +4 / +8 |
| 中张明杠 / 暗杠 | +8 / +16 |
| 幺九明杠 / 暗杠 | +16 / +32 |

一般合计向上取整到 10 符。七对子始终 25 符；平和自摸 20 符、平和荣和 30 符。副露的零加符荣和形按 30 符，不能给它“平和役”。荣和补成的刻子按明刻算符，但整副牌仍可保有门清荣和资格。雀魂岭上自摸也给通常的自摸 2 符。

符表补充：[Fu](https://riichi.wiki/index.php?mobileaction=toggle_view_desktop&title=Fu)、[符数与点数速记](https://riichi.wiki/Score_table_memorization)；连风与岭上特例见 [官方段位规则](https://mahjongsoul.com/news/46)。

对未到满贯的牌，令 `B = 符 × 2^(番+2)`。每一笔付款分别向上取整到百点：

| 和牌方式 | 四麻付款 |
|---|---|
| 闲家荣和 | 放铳者支付 `4B` |
| 庄家荣和 | 放铳者支付 `6B` |
| 闲家自摸 | 庄家支付 `2B`，两位闲家各支付 `B` |
| 庄家自摸 | 三位闲家各支付 `2B` |

公式中的 `+2` 已含计分用的底倍数，不把它额外记成两个可起和的役番。

| 档位 | 条件 | 闲家荣和 | 庄家荣和 |
|---|---|---:|---:|
| 满贯 | 5 番；或 4 番 40 符及以上；或 3 番 70 符及以上 | 8000 | 12000 |
| 跳满 | 6–7 番 | 12000 | 18000 |
| 倍满 | 8–10 番 | 16000 | 24000 |
| 三倍满 | 11–12 番 | 24000 | 36000 |
| 累计役满 | 13 番及以上，非真正役满牌 | 32000 | 48000 |
| 单倍真正役满 | 满足役满 | 32000 | 48000 |

真正多倍役满按倍数增加。普通雀魂不采用切上满贯：4 番 30 符、3 番 60 符的闲家荣和为 7700，庄家为 11600。友人/比赛规则可能改动。

公式及档位参考：[日麻计分说明](https://riichi.wiki/Goumii)；雀魂不切上满贯核对：[雀魂四麻规则记录](https://note.com/qar13ktk20/n/nf9c7cf0eb025)。

### 6.2 本场、供托与多家荣和

本场是桌上的连庄/流局累积计数，不是立直棒。

- 四麻每本场：荣和额外 300 点；自摸时每家额外付 100 点。
- 三麻每本场：荣和额外 200 点；自摸时另两家各付 100 点。
- 单人和牌通常取得全部现存立直供托；荒牌流局继续保留，整场结束时余供托归第一名。
- 多家荣和时，每家各结算自身和牌点；**本场加点和供托由距放铳者行动顺序最近的和牌者取得**，不是给每人复制一份。

来源：[官方段位规则](https://mahjongsoul.com/news/46)；三麻本场补充：[Mahjong Soul 规则汇总](https://riichi.wiki/Majsoul)。

### 6.3 包牌/责任支付

雀魂对大三元、大四喜采用包牌。让对手通过关键副露确定这项役满者，承担该项役满的责任支付：自摸时包牌者支付全部；另一人放铳时通常由包牌者与放铳者各承担一半。本场按责任支付规则处理。

复合役满只对被包的役满部分应用责任支付。四杠子没有包牌，也没有因大明杠后岭上自摸而自动触发的“包杠”。复杂多人和牌与责任支付同时出现时，应核对客户端结算，不套用普通均分公式。

来源：[官方段位规则](https://mahjongsoul.com/news/46)、[中文官方规则](https://www.maj-soul.net/homepage/scripts/RuleList.json)。

## 7. 流局、连庄与整场结束

### 7.1 荒牌流局

可摸的普通牌山耗尽，无人和牌时进入荒牌流局。四麻王牌保留 14 张，不会把全部牌都正常摸完。

四麻若只有部分人听牌，由未听者合计向听牌者支付 3000 点：1 人听收 3000；2 人听各收 1500；3 人听各收 1000。全听或全不听不支付。

三麻总听牌料为 2000 点：1 人听时另两人各付 1000；2 人听时未听者付 2000，由两人各收 1000。全听/全不听为零。

允许形式听牌、振听状态的听牌；等待牌全部在外部可见，不等于结构不听。但自己占满同种四张、只能等待不存在的第五张，不是有效听牌。

### 7.2 途中流局与流局满贯

| 项目 | 条件摘要 | 四麻 | 三麻 |
|---|---|---|---|
| 九种九牌 | 自己首个摸打机会前没有鸣牌打断，手牌至少 9 种幺九牌；可以主动选择流局，也可继续 | 有 | 有，拔北也会打断资格 |
| 四风连打 | 无鸣牌打断，四家第一张弃牌是同一种风牌 | 有 | 无 |
| 四家立直 | 四家立直成立，第四家宣言牌未被荣和 | 有 | 无；三家立直继续 |
| 四杠散了 | 至少两家合计四杠；仍须处理第四杠后的和牌机会 | 有 | 有 |
| 三家和了流局 | 同一弃牌被三家荣和而流局 | **无，按三家荣和处理** | 不适用 |

一人四杠不会因为“四杠散了”流局，可继续完成四杠子，但不能再出现第五杠。途中流局连庄、本场增加；不进行通常的听牌料清算。

**流局满贯**是另一种荒牌结算：自己的所有弃牌均为幺九牌，且没有被他家鸣走。本人可以副露，不要求门清。满足时以满贯自摸式付款代替听牌料；可以多人同时成立。雀魂把它用于流局结算，庄家是否连庄看其是否听牌，不能按“庄家流满等于普通庄家和牌”推导。四家立直/四杠散了等途中流局不触发流局满贯。

来源：[中文官方规则](https://www.maj-soul.net/homepage/scripts/RuleList.json)、[日服详细规则](https://mahjongsoul.com/news/46)；听牌料及流满补充：[雀魂规则记录](https://note.com/qar13ktk20/n/nf9c7cf0eb025)、[Mahjong Soul](https://riichi.wiki/Majsoul)。

### 7.3 连庄与轮庄

庄家普通和牌，或荒牌流局时庄家听牌，通常连庄。本场增加。闲家和牌通常轮庄并清本场；荒牌流局时庄家未听则轮庄，但本场继续增加。多家荣和中只要包含庄家，采用连庄规则；仍要检查整场终止条件。

### 7.4 东风、半庄、延长与击飞

| 模式 | 通常局序，不计连庄 | 原点/返还基准 | 第一名终局门槛 |
|---|---|---:|---:|
| 四人东 | 东一至东四 | 25000 | 30000 |
| 四人南/半庄 | 东一至东四，再南一至南四 | 25000 | 30000 |
| 三人东 | 东一至东三 | 35000 | 40000 |
| 三人南/半庄 | 东一至东三，再南一至南三 | 35000 | 40000 |

“四人南”是东南两场，不是只打南场。连庄可能使实际局数超过上表。

- 常规最后一局完成后，若第一名不足门槛，东风战南入，半庄战西入。
- 延长采用达标结束机制；东风最多延长至南场，半庄最多至西场，不无限延伸。
- 连庄与延长终局有优先级例外；日服详规明确，多家荣和包含庄家的情况下可优先连庄。中文文本给出的连庄例外更宽泛，见第 12 节。
- 最后一局庄家已是第一且达到门槛时，符合和牌止/听牌止条件会自动终局。
- 任一人点数 **小于 0** 会击飞终局；恰好 0 点继续。负分仍计入结算。
- 同分按东一局最初座位东、南、西、北的先后顺序定高低；三麻没有北座。
- 对终局门槛采用“达到”而非“严格超过”的日服详细说明；精确等于门槛及延长例外需留意来源差异。

来源：[官方段位规则](https://mahjongsoul.com/news/46)、[中文官方对局规则](https://www.maj-soul.net/homepage/scripts/RuleList.json)。

## 8. 三人麻将专属规则

三麻继承通用立直麻将框架，但必须替换以下规则：

| 项目 | 普通雀魂三麻 |
|---|---|
| 牌组 | 移除全部 `2m–8m`，剩 27 种、108 张 |
| 座位 | 东、南、西；没有北家 |
| 吃 | 禁止；碰、杠保留 |
| 原点 / 第一名门槛 | 35000 / 40000 |
| 赤牌 | 赤五筒、赤五索各一张 |
| 岭上牌 | 8 张 |
| 北 | 可留作普通客风牌，或拔北成为宝牌；不是所有人的役牌 |
| 自摸 | 自摸损：缺席北家的付款不由其他人补齐 |
| 途中流局 | 九种九牌、四杠散了；没有三家立直流局 |
| 多人荣和 | 支持双响 |
| 每本场 / 总听牌料 | 200 / 2000 |

**拔北细则：** 拔出一张北后补摸一张岭上牌，和牌时每张拔北至少给一份拔北宝牌；若北同时是指示牌对应宝牌，还可叠加。拔北不破坏门清，已拔北不占手牌结构，因而不破坏断幺九、清一色等牌型。拔北会打断一发、两立直、地和、九种九牌的未鸣牌条件。补牌直接和了可成立岭上开花。

他家拔北存在抢北和的窗口，但抢北行为本身不提供“抢杠”役；仍必须有其他合法役，且不振听。不要把“只能国士抢暗杠”错误扩展为“只能国士抢北”。

**自摸损例子，无本场供托：** 闲家满贯自摸时，庄家付 4000，另一闲家付 2000，总收 6000；庄家满贯自摸时，两位闲家各付 4000，总收 8000。荣和仍为闲家 8000、庄家 12000。友人房可存在不同自摸结算设置。

由于没有万子顺子，三色同顺不可能成立；三色同刻仍可能以 1 或 9 成立。一气通贯及九莲只能在筒或索构成。

来源：[中文官方规则](https://www.maj-soul.net/homepage/scripts/RuleList.json)、[官方三麻详规](https://mahjongsoul.com/news/46)、[官方自摸损 FAQ](https://mahjongsoul.com/faq)；计分例子核对：[雀魂三麻自摸损表](https://riichi.wiki/Template%3AMajsoul/3P-Mahjong_scoring_table)。

## 10. 段位、房间与积分

### 10.1 段位与准入

段位顺序：**初心 → 雀士 → 雀杰 → 雀豪 → 雀圣 → 魂天**。魂天前各大段位通常分 1–3 星；三麻和四麻的段位各自独立。

| 段位房间 | 通常可进入的段位 |
|---|---|
| 铜之间 | 初心、雀士 |
| 银之间 | 雀士、雀杰 |
| 金之间 | 雀杰、雀豪 |
| 玉之间 | 雀豪、雀圣 |
| 王座之间 | 雀圣、魂天 |

房间还可能要求铜币余额、入场费，并受可用局制等条件约束；具体数值读取当前客户端。段位升高后并非始终可以返回所有低级房间。

段位顺序由 [官方入门指南](https://mahjongsoul.com/startguide/)确认；房间准入与三四麻独立等细节参考社区 [Mahjong Soul](https://riichi.wiki/Majsoul)，使用时核对当前段位场面板。

### 10.2 分清三种结果

1. **局内点数变化：** 由和牌、流局听牌料、本场、供托等产生。
2. **整场顺位：** 最终点数排序，必要时用初始座次破同分。
3. **段位积分变化：** 普通段位综合最终点数、顺位马点、房间/局制奖励与段位末位惩罚；魂天另用魂珠制度。

社区整理的非魂天通常公式：

```text
段位积分变化 = ceil((最终点数 - 原点) / 1000 + 顺位马点 + 段位场修正)

四麻原点：25000；马点：[+15, +5, -5, -15]
三麻原点：35000；马点：[+15, 0, -15]
ceil 表示数学上的向上取整，负值也向正无穷方向取整。
```

房间和东/南场影响前列奖励，玩家自身段位影响末位惩罚。四麻第三、三麻第二的某项段位修正为零，**不等于总积分不变**。例如四麻第三名恰好 25000 点，仅马点就带来 -5；不能只看“第三名基础分 0”。

公式、精确升降段阈值、保护机制和魂珠表应以当前客户端为准。魂天有单独等级与魂珠增减，也存在降回雀圣的情况，不沿用早期“魂天永不降段”的说法。

马点由 [官方段位规则](https://mahjongsoul.com/news/46)确认；公式、取整和魂天机制为社区补充：[Mahjong Soul 段位计算](https://riichi.wiki/Majsoul)。本文不复制整张易变的段位奖惩表。

### 11.2 推荐判断顺序

1. **校验数据：** 区分摸入牌与既有手牌；核对副露、杠、拔北及每种最多四张；三麻剔除 `2m–8m`。
2. **判断形状：** 分别检查普通形、七对子、国士；枚举完成形待牌。
3. **判断役：** 按门清/副露、场风/自风、和牌事件确定真正役；之后才计宝牌。
4. **判断荣和权：** 检查整套听口与自己弃牌历史、临时振听、立直见逃；不能只检查眼前一张。
5. **计算得分：** 采用高点法，算番符或役满，按庄闲与三四麻结算，再处理本场、供托、包牌及多家荣和。
6. **更新牌局：** 判断流局/连庄/轮庄，再判断击飞、最后一局和延长终止；应用对应规则优先级。
7. **解释结果：** 把确定事实、规则推导和未知条件分开。策略建议不能写成规则要求，例如“有役不等于必须立直”。

### 11.3 常见误判检查表

| 问题/说法 | 应检查或纠正 |
|---|---|
| “有宝牌为什么不能和？” | 是否真正有役；宝牌不是役 |
| “已经四组加一对了” | 只说明结构完成，还要查役与振听 |
| “另一张没打过，为什么也振听？” | 一张当前待牌触发即可封锁全部荣和 |
| “没点跳过，为什么临时振听？” | 无役不能荣和的完成形牌也可能触发 |
| “自摸一定是一番” | 仅门清自摸本身是役，副露后须有其他役 |
| “暗杠后不能立直” | 暗杠不破坏门清，仍需满足其他立直条件 |
| “三响应流局” | 雀魂普通四麻三家分别荣和 |
| “拔北就不门清了” | 拔北保留门清，但打断一发等条件 |
| “抢北就自动有役” | 抢北本身不给抢杠役 |
| “到 30000 就立刻结束” | 先确认是否最后一局/延长及连庄例外；常规东一达标不自动终局 |
| “0 点一定被飞” | 负点才触发普通击飞 |
| “三麻满贯自摸少算了” | 段位三麻采用自摸损 |
| “第三名一定不掉段位分” | 总积分仍包含素点与马点 |
| “观战所有手牌都可用于当时决策” | 复盘全知视角与玩家当时可见信息不同 |

## 12. 已发现的来源差异与复核边界

本次实际读取了中、日官方正文，不仅依赖搜索摘要。官方网页有部分旧文案，不能因为域名官方就忽略内部矛盾。

| 边界 | 来源差异 | 本文处理 |
|---|---|---|
| 恰好 30000/40000 | 中文文本写“超过”，日服详规写“以上” | 采用达到门槛；精确判定时核对对应服当前界面/牌谱 |
| 延长与连庄优先 | 中文写存在庄家连庄则优先；日服明确列出双响含庄的例外 | 保留连庄例外，不给出适用于全部事件的单条终局公式 |
| 末尾立直 | 中文四麻/三麻均写剩余至少 4 张；日服写仍有摸牌机会 | 不推导三麻只剩 3 张等边界，交当前合法动作列表核对 |
| 同巡振听结束 | 中文写自己切牌后；日服写下次自己摸牌/摸牌番 | 以自己的下一次正常摸打周期说明；代码实现须验证鸣牌、补牌等事件节点 |
| 立直后暗杠 | 中文写不改变听牌型；日服规则允许牌姿/役变化但要求听牌种类不变，FAQ 又提种类与枚数 | 保留更具体限制，不能套用其他平台“任何拆分变化都禁杠”的规则 |
| 三麻最后局编号 | 中文三麻段落仍出现“东四/南四” | 视为沿用四麻文案；三麻一场三个庄位，写东三/南三 |
| 动态游戏数值 | 铜币要求、段位奖惩、卡池概率、分析权益会调整 | 只保留机制及已标注的社区公式，精确值读当前客户端 |

以下内容未作为完整可执行规范核实：所有特殊活动规则、每一种抢杠/拔北与海底的事件顺序、多家流满与包牌叠加的所有结算组合、超时/断线后的各版本自动动作、各平台帐号互通和付费资产互通。遇到这些问题应查对应版本文档或牌谱，不能自行补全。
